# HariShop Market (Forge 1.20.1)

A multi-shop market mod for Minecraft 1.20.1 with server-side transaction validation and compatibility hooks for supported currency mods.

This repository contains the source and Gradle build files for the Forge 1.20.1 release. The project is organized into common, forge, fabric, and quilt modules.

## Build

Use JDK 17.

Windows:
    .\gradlew.bat :forge:build
    .\gradlew.bat :common:test
